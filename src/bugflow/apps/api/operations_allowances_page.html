Allowances

Sign in to see and change what a scope may spend.

A part left empty means any. A scope inherits every allowance of a wider scope that covers it, and a run in it must keep within all of them.

Each run is handed

On each resource, the lowest limit of the allowances per run that cover this scope, and the allowance it comes from.

Allowances that apply

Most specific first. An allowance per period is measured over its own scope's spend in its current period.

Declare an allowance for this scope

Sets this scope's own allowance for the cadence, replacing what it holds for it. An empty limit is no limit; zero allows nothing. Revoking an allowance is not allowing zero: it leaves the scope to the wider allowances that cover it.
